RetailPro – Proyecto de Data Analytics

Descripción del proyecto
RetailPro es un proyecto desarrollado en el marco del curso de Data Analytics. Su objetivo es aplicar herramientas y técnicas de análisis de datos para trabajar con información comercial, consultar bases de datos, obtener resultados y generar información útil para la toma de decisiones.

A lo largo de los distintos módulos se desarrollan actividades relacionadas con SQL, consultas de datos y visualización mediante herramientas de análisis.

Herramientas utilizadas
SQL Server: motor de base de datos utilizado para almacenar y consultar información.
SQL Server Management Studio (SSMS): entorno utilizado para ejecutar y administrar consultas SQL.
Power BI: herramienta utilizada para el análisis y la visualización de datos.
GitHub: plataforma utilizada para almacenar, organizar y documentar los archivos del proyecto.

Cómo ejecutar los scripts SQL

Para ejecutar los archivos SQL correspondientes a los módulos 3, 4 y 5:

Abrir SQL Server Management Studio (SSMS).
Conectarse a la instancia de SQL Server correspondiente.
Abrir el archivo .sql del módulo que se desea ejecutar.
Seleccionar la base de datos Ventas_Tech_DB.
Ejecutar el script utilizando el botón Execute o la tecla F5.
Revisar los resultados en la ventana de resultados de SSMS.

Importante: seleccionar la base de datos correcta antes de ejecutar cada script.

Cómo abrir el proyecto de Power BI

Para consultar el trabajo correspondiente al módulo 8:
Abrir Power BI Desktop.
Seleccionar el archivo .pbix ubicado en la carpeta del Módulo 8.
Si corresponde, actualizar los datos y verificar las conexiones configuradas.
Explorar los informes y visualizaciones desarrollados.

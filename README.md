# Data Analytics - Coderhouse

Este repositorio contiene los scripts de SQL desarrollados a lo largo del curso de Data Analytics de Coderhouse. Aquí se irán subiendo las entregas y ejercicios correspondientes a cada módulo del programa.

## Objetivo

Centralizar y organizar las consultas, ejercicios y entregas de SQL para llevar un registro claro del progreso en el curso y compartir los trabajos realizados.

## Contenido del repositorio

El repositorio está estructurado por módulos para facilitar la navegación y la revisión de cada entrega.
